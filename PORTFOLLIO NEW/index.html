03 / Perspective

How I think about building software

Start from the problem

AgriLink began with the gap between farmers and buyers, and Unified Scholarship with students missing opportunities. The problem comes first, then the stack.

Own the whole stack

From the React interface to the Express routes and the MySQL tables underneath, I like understanding how each layer talks to the next.

Build for real users

Role-based dashboards, multilingual support and verification workflows come from thinking about who actually uses the product.

Build it. Then make it better.
